# 🤖 UtpalAI – Gemini AI Clone

Welcome to **UtpalAI**, an open-source clone of Google's Gemini AI. This project replicates key multimodal AI capabilities—think chat, image understanding, and natural interaction—all from the comfort of your local machine.

[🚀 Visit the Repository](https://github.com/Dehury-Utpal/UtpalAI)

---

## 🔴 Live Demo
[🚀 Visit the Site](https://utpal-ai.vercel.app/)

## 🌟 Features

- 🧠 **Multimodal AI** – Handles both text and images.
- 💬 **Conversational Agent** – Human-like chat experience.
- 🖼️ **Image-to-Text Capabilities** – Ask about images you upload.
- ⚡ **Lightweight & Fast** – Optimized for performance.
- 🛠️ **Easy to Extend** – Modular structure for quick customization.
